# 최종 수용 검사표 — 직접 확인한 뒤 체크하기

기준 프로젝트: `HCI_Diver_Hands_Final` / Unity **6000.3.27f2**.

최신 요청의 중복 번호를 통합하여 아래 10개 묶음으로 정리했습니다. **코드와 Scene에 반영한 상태이며, 아래 체크박스는 실제 Unity·Quest 결과가 아직 없으므로 모두 비워 두었습니다.** 각 행동을 실제로 성공시킨 뒤에만 체크합니다.

## A. 실행 준비

- [ ] 새 폴더를 Unity Hub의 기존 프로젝트 추가로 열고 Editor가 6000.3.27f2인지 확인했다.
- [ ] 패키지 복원이 끝났고 Console에 빨간 컴파일·임포트 오류가 없다.
- [ ] `Simulation.unity`에서 `HCI > Validate Hands Demo`를 실행하고 보고된 오류를 해결했다.
- [ ] Play에서 UI·생물·수면이 나타나며 분홍색 재질이나 Missing Script가 없다.
- [ ] Quest 실행에서 양손이 추적되며 컨트롤러 없이 메뉴를 사용할 수 있다.

## 1. 통화 음량·받았는지 알 수 있는 상태 표시

- [ ] 전화가 오면 벨과 큰 INCOMING CALL·상대 이름을 확인할 수 있다.
- [ ] ANSWER를 누르면 벨이 멈추고 CONNECTED·연결 확인음·상대 목소리가 나타난다.
- [ ] END를 누르면 목소리가 멈추고 CALL ENDED·종료 확인음이 나타난다.
- [ ] Elina 발신 응답에 제공한 answering 녹음, 수신 통화에 Calling 녹음이 재생된다.
- [ ] 물속 주변음이 있는 상태에서도 실제 Quest에서 목소리와 연결 확인음을 구분할 수 있다.
- [ ] 전화 패널을 닫아도 진행 중 통화가 끊기거나 상태 표시가 사라지지 않는다.

## 2. 확인 버튼 — 직접 터치와 레이저+주먹

- [ ] 검지를 펴서 ANSWER·CALL·일반 메뉴에 각각 닿으면 한 번 선택된다.
- [ ] 손가락을 계속 붙여 두어도 반복 실행되지 않으며, 뗐다가 다시 누를 수 있다.
- [ ] 레이저로 버튼을 가리키고 편 손을 주먹으로 쥐면 한 번 선택된다.
- [ ] 이미 주먹인 손으로 버튼 위를 지나가면 자동 클릭되지 않는다.
- [ ] 오른손 엄지척 자세의 접힌 검지가 가까운 버튼을 누르지 않는다.
- [ ] 왼손으로 UI를 선택할 때 동시에 앞으로 튀지 않는다.
- [ ] 손을 추적 범위 밖으로 뺐다가 다시 보여도 원하지 않은 클릭·이동이 발생하지 않는다.
- [ ] 앞쪽 통화 팝업 뒤에 가려진 메뉴가 함께 눌리지 않는다.

## 3. 왼손 스와이프와 왼팔의 동일 메뉴

- [ ] 왼손 손바닥을 바깥쪽으로 하고 오른쪽으로 스와이프하면 화면 원형 메뉴가 열린다.
- [ ] 왼쪽으로 스와이프하면 화면 메뉴가 닫힌다.
- [ ] 왼팔 위의 INFO·SOS·CALL·FIND·CREW 버튼이 팔을 따라 움직인다.
- [ ] 왼팔 버튼을 오른손으로 누르면 화면 메뉴의 같은 이름 버튼과 같은 기능이 열린다.
- [ ] 왼손등에서 스와이프로도 화면 메뉴를 열 수 있다는 짧은 안내가 읽힌다.
- [ ] 왼손 추적을 잃으면 팔 UI가 허공에 남아 오작동하지 않는다.

## 5. 왼손 전진과 오른손 엄지 위·아래를 동시에 사용

- [ ] 바다 쪽으로 이동해 머리가 실제 수면 아래에 들어간 뒤 검사했다.

## 8. 상단 O2·배터리·실제 머리 수심·잠수 시간

- [ ] O2 막대는 파란색이고 위에 O2가 보인다.
- [ ] 배터리 막대는 연두색이고 위에 배터리 픽토그램이 보인다.
- [ ] **배터리 15%와 그 이하**에서 막대가 주황색이고 경고가 보인다.
- [ ] 배터리 오른쪽 DEPTH는 실제 머리가 수면 아래로 내려갈수록 증가한다.
- [ ] 머리가 물속에 들어가면 수심 오른쪽 DIVE TIME이 나타나 증가한다.
- [ ] 수면 위에서는 DEPTH가 0.0m이고 DIVE TIME은 숨겨진다.
- [ ] 다시 잠수하면 새 잠수 시간이 00:00부터 시작한다.

검사 팁: 배터리 소비율과 산소 소비율은 `00_Systems`의 InformationManager에서 읽을 수 있습니다. 빨리 확인하려고 Play 중 값을 바꾸었다면 Play를 끝내고 실제 시연 설정이 유지되는지 확인합니다. 최종 파일에는 검사 때문에 바꾼 소비율을 저장하지 않습니다.
