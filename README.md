This fork is created by Yan Zhu. I added more animated boats/divers, more sea life and underwater atmosphere effects to the Augmented Scuba Diving simulation.

## Features

- Animated crewmate boats (bobbing, rolling, pitching) + Script that generates more boats
- Scuba divers that walk on the sea floor and avoid collision with the rocks + Script that generates more divers
- New call audio for the diver Louis
- More swimming fish
- Darker the water color when user goes deeper
- Floating particles in the water
